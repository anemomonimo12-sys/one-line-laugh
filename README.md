# The One-Line Laugh

Entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)
on make.fun — one funny line, at most 200 characters, any topic.

## How it works

`main.py` (Python 3.13) writes a single fixed, original one-liner to
`/output/entry.txt`. It is fully deterministic: no randomness, no network,
no clock.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## The line

> I bought noise-cancelling earbuds to finally hear myself think, and it turns out I have nothing to say.
